## Overview

The Stripe FPGA resides on each Collector Box and manages **6 detector stripes** (SBX channels). Each stripe has 5 SBX channels (digitizer cards), giving 30 channels per Collector Box.

**Functions per stripe:**
- **Relay control** - 3 relay types per channel: current injection (irly), ground fault check (grly), 48V power enable (prly)
- **Clock & sync distribution** - enable/disable clock/sync per channel, manual override of clock source and output enable, trigger-sync enable, clock relay (crly) earth and signal relays
- **SBX port tristate control** - SPI bus and clock/sync tristate per channel
- **Status readback** - stripe ID, SBX clock source/enable, DCM PLL lock status (trigger DCM + oscillator DCM)
- **LED pulser control** - two LED control registers per odd-numbered stripe (s1/s3/s5); even stripes have sandbox registers at those addresses
- **Firmware identity** - code_revision per stripe

The register block (`COMP_REGISTERS`) is spreadsheet-generated VHDL using ANL's Excel VBA framework. There are **48 registers total** (8 per stripe × 6 stripes). ✅ verified 2026-04-27 - `StrpFPGAinitializer.h:L2-49` (all 48 struct members with addresses); `StrpFPGA_registers.vhd:L130-177` (full register array).

## relay_control_sN

**Addresses:** 64 (s1), 72 (s2), 80 (s3), 88 (s4), 96 (s5), 104 (s6)
**Write mask:** 0x7FFF (15 bits used)
**EPICS PV type:** `bo` (binary output, per bit)
**Bus:** `CollectorLocalSerial`

Controls 3 relay types for each of the 5 SBX channels in a stripe:

| Bit range | Relay type | Function |
|-----------|------------|----------|
| [4:0]     | `irly_sN_1`-`irly_sN_5` | Ground test **current injection relay** enable per SBX channel (0=normal, 1=ground_current_injection) | ✅ `StrpFPGA.db:L2,17,32,47,62` |
| [9:5]     | `grly_sN_1`-`grly_sN_5` | **Ground fault check relay** enable per SBX channel (0=normal, 1=ground_open) | ✅ `StrpFPGA.db:L77,92,107,122,137` |
| [14:10]   | `prly_sN_1`-`prly_sN_5` | **48V power enable relay** per SBX channel (0=off, 1=on) | ✅ `StrpFPGA.db:L152,167,182,197,212` |

Bits 15-31 unused (masked to 0x7FFF).

## stripe_control_sN

**Addresses:** 65 (s1), 73 (s2), 81 (s3), 89 (s4), 97 (s5), 105 (s6)
**Write mask:** 0xFF1F (bits 5–7 unused) ✅ verified 2026-04-30 — `StrpFPGA_registers.vhd:L277-289` (bits 0-4 assigned, then jumps to bit 8; bits 5-7 never driven = unused; write mask `X"FF1F"` at L136)
**EPICS PV types:** `bo` per bit; also an `ao` aggregate write record (`GS${DetNbr}_stripe_control_sN`)
**Aggregate write mask used in StrpFPGA_reg.db:** `0x00E0` (writes bits 7:5 only — clock control group)

| Bit | Signal | Function |
|-----|--------|----------|
| [4:0] | `clock_and_sync_enable_sN_1`-`_5` | Enable clock and sync distribution to each SBX channel (one bit per channel) |
| 5-7 | (unused) | Not connected |
| 8 | `crly_earth_sN` | Clock relay earth contact |
| 9 | `crly_signal_sN` | Clock relay signal contact |
| 10 | `trig_sync_enable_sN` | Enable trigger synchronization for the stripe |
| 11 | `manual_sync_sN` | Manual sync pulse (write 1 to fire a sync) |
| 12 | `clock_output_enable_override_sN` | Override the automatic clock output enable logic |
| 13 | `manual_clock_output_enable_state_sN` | Manual clock output state when override is active |
| 14 | `clock_source_override_sN` | Override the automatic clock source selection |
| 15 | `manual_clock_source_select_sN` | Clock source select when override is active (0=internal, 1=external) |

## led_control

**Addresses (stripe 1):** 68 (led_control_s1_1), 69 (led_control_s1_2)
**Addresses (stripe 3):** 84 (led_control_s3_1), 85 (led_control_s3_2)
**Addresses (stripe 5):** 100 (led_control_s5_1), 101 (led_control_s5_2)
**Write mask:** 0xFFFF
**EPICS:** `asynParamUInt32Digital` (PV name: `reg_led_control_sN_M`)

LED pulser control registers for the **odd-numbered stripes** (s1, s3, s5). Each stripe has two LED control words (16-bit). These control test LED pulse injection into the HPGe detectors (used for gain calibration and detector commissioning).

Even-numbered stripes (s2, s4, s6) have **sandbox registers** at these addresses instead (see below).

## sandbox_regs

**Addresses (stripe 2):** 76, 77
**Addresses (stripe 4):** 92, 93
**Addresses (stripe 6):** 108, 109
**Write mask:** 0xFFFF
**EPICS:** `asynParamUInt32Digital` (PV names: `reg_sandbox_reg_sN_1`, `reg_sandbox_reg_sN_2`)

Writable scratch registers with no hardware function. Present in even-numbered stripes at the addresses where odd stripes have LED control registers. Useful for EPICS readback verification.

## reserved

**Addresses:** 70 (s1), 78 (s2), 86 (s3), 94 (s4), 102 (s5), 110 (s6)
**Read mask:** 0xFFFF; **write mask:** 0x0000 (read-only)
**Reset value:** 0x00002208

Nominally used as `CODE_DATE` (firmware build date) but marked reserved in the VHDL comments because it **may be repurposed**. Do not rely on this for firmware dating without verifying current use.

---

## code_revision

**Addresses:** 71 (s1), 79 (s2), 87 (s3), 95 (s4), 103 (s5), 111 (s6)
**Read mask:** 0xFFFF; **write mask:** 0x0000 (read-only)
**Reset value:** 0x00000010

FPGA firmware build number for each stripe's FPGA. Each stripe has its own independent revision number - they can carry different firmware versions.

## EPICS PV Naming

PV names follow the pattern: `GS${DetNbr}_<signal_name>`

Where `${DetNbr}` is the detector/collector number substituted at IOC boot.

Examples:
- `GS42_irly_s1_1` - current injection relay, stripe 1, channel 1, detector 42
- `GS42_prly_s3_5` - 48V power relay, stripe 3, channel 5, detector 42
- `GS42_clock_and_sync_enable_s2_3` - clock/sync enable, stripe 2, channel 3
- `GS42_sbx_clock_source_s1` - SBX clock source status, stripe 1
- `GS42_dcm_trig_locked_s4` - trigger DCM lock, stripe 4
- `GS42_stripe_id_s6` - hardware stripe ID, stripe 6
- `reg_relay_control_s1` - raw asyn parameter name (no detector prefix)

EPICS record DTYP is `CollectorLocalSerial` for all control/status records.

## Address Layout Summary

Stripe groups are interleaved: each group of 8 registers occupies 8 consecutive addresses, with the 6 stripes mapped as columns:

```
Addr 64-71 : Stripe 1 (relay_ctrl, stripe_ctrl, tristate_ctrl, status, led1, led2, reserved, code_rev)
Addr 72-79 : Stripe 2 (relay_ctrl, stripe_ctrl, tristate_ctrl, status, sandbox1, sandbox2, reserved, code_rev)
Addr 80-87 : Stripe 3 (relay_ctrl, stripe_ctrl, tristate_ctrl, status, led1, led2, reserved, code_rev)
Addr 88-95 : Stripe 4 (relay_ctrl, stripe_ctrl, tristate_ctrl, status, sandbox1, sandbox2, reserved, code_rev)
Addr 96-103: Stripe 5 (relay_ctrl, stripe_ctrl, tristate_ctrl, status, led1, led2, reserved, code_rev)
Addr 104-111: Stripe 6 (relay_ctrl, stripe_ctrl, tristate_ctrl, status, sandbox1, sandbox2, reserved, code_rev)
```

Pattern within each stripe group (offset 0-7):
- +0: relay_control
- +1: stripe_control
- +2: tristate_control
- +3: stripe_status
- +4: led_control_1 (odd stripes) / sandbox_1 (even stripes)
- +5: led_control_2 (odd stripes) / sandbox_2 (even stripes)
- +6: reserved (CODE_DATE)
- +7: code_revision
