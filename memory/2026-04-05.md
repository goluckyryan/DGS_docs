## Key Technical Facts Documented Today

### trigger_mux_select modes (DIG firmware):
| Value | Mode | Meaning |
|-------|------|---------|
| 0 | IntAcptAll | Internal accept all — PEQ bypassed, calibration/LED mode |
| 1 | ExtTTL | External TTL via Aux I/O pin 32/33 (AUX_DIN[10]) |
| 2 | ExtTTCL | Normal physics mode — waits for MTRG→RTRG→DIG trigger decision |
| 3 | Diag | Auto-triggers on 16-bit timestamp rollover |

### TTL injection point:
- **AUX_DIN[10]** = pins 32/33 on 36-pin front panel Aux I/O header (RS485 differential)
- MSbit of 11-bit aux bus; this is the "front panel external discriminator input"
- ⚠️ Direction must be set to INPUT for bit 10 to receive TTL signal

### MTRG NIM I/O (physical layout):
- 4 LEMO connectors in 2×2 grid at **bottom of MTRG front panel**, just above the ejector handle
- **TOP row = NIM outputs** (OUT 1, OUT 2)
- **BOTTOM row = NIM inputs** (IN 1, IN 2)
- NIM IN 1 = Auxiliary trigger input (`EN_NIM_AUX` PV)
- NIM IN 2 = Veto input / TAC-II TDC input
- Left vs right within each row — silkscreen on board is ground truth; not explicitly stated in docs
- Source: `Trigger user manual 20140901.pdf` + `Master Trigger Registers Master Document.pdf`

### MTRG front panel layout (top to bottom):
1. Status LEDs
2. SERDES link connector (125-pin, 2mm hard metric)
3. CPLD ribbon cable connectors (SUM A/B/C/D, FAST STROBE)
4. Auxiliary I/O connector
5. NIM I/O (4× LEMO, 2×2, at very bottom)
6. Ejector handle

### TTCL vs TTL summary:
- TTL = simple voltage-level signal, wire-level, used for bench testing
- TTCL = full serial protocol (1 Gbps SERDES, LVDS), timestamped trigger commands, < 250 ps jitter system-wide

### MDIG vs SDIG documented
- Same physical board, different firmware (SLAVE_MODE compile flag)
- MDIG: SERDES link to RTRG, sends multiplicity up, distributes trigger/clock down via front-bus ribbon
- SDIG: no SERDES to RTRG, receives trigger/clock from MDIG only, throttle request is only upstream signal
- Written up in `hardware_architecture.md` with full table — committed
