### collectorboxpi Deep Study (last task, session ended mid-study)
Read `Pre_EPICS_Collector/README.md` and `CollectorBox_RevA/README.md` in detail. Key findings:
- **Pre_EPICS_Collector**: Standalone C utilities using bcm2835 SPI library for commissioning before EPICS. 15 executables. Normal procedure: `ALL_power_OFF → Scan_Collector_FPGAs → Scan_DVI_Power → Scan_DVI_Comms → GenerateCmdFile.py`
- **SPI architecture**: SPI1 (aux), 24-bit transactions (R/W + 7-bit addr + 16-bit data), 5-bit DEVSEL GPIO bus (up to 32 devices)
- **4 collector boxes**: pi0=201 (SE, even GS 2-60), pi1=202 (SW, even 62-110), pi2=203 (NE, odd 1-59), pi3=204 (NW, odd 61-109)
- **Box geometry**: cable→VMEGS formula per box; actual GS hole from DNG_ID in scan file
- **CAMAC hex bitmask**: EPICS 7.0 handles `A0xFFF0` correctly via unsigned short cast in device support — no fix needed
